# 第三次作业 — 求和（sum）学习笔记 ✅

## 目录（文件夹内容） 📁
- `sum.asm` — 原始汇编：计算 1 到 100 的和并把结果写入数据段变量 `sum`；含打印子例程 `print_num`（用 `int 21h` 输出）。
- `sum2.asm` — 结果保存在寄存器（AX）的版本并打印。
- `sum3.asm` — 结果保存在栈中（`push ax`）的版本并打印。
- `sum-plus.asm` — 带用户输入（缓冲读取 + 字符串转数字 + 范围校验 1..100）并计算 1..n 的和。
- `sum.c` — `sum.asm` 的 C 实现（1..100 的和）。
- `sum_plus.c` — `sum-plus.asm` 的 C 实现（带输入和校验）。
- `sum-disasm.asm` / `sum-plus-disasm.asm` — 两个 C 程序的反汇编并带注释（用于分析编译器生成的汇编）。
- `SUM*.EXE`, `*.OBJ` — 示例生成的目标文件与可执行文件。



## 程序功能概述 🔍
- `sum.asm`：计算 1 到 100 的累加和，结果写入数据段变量 `sum`，然后用 `print_num` 子程序将结果以十进制逐位输出。
- `sum2.asm`：将累加器留在寄存器 `AX` 中作为结果，随后打印。
- `sum3.asm`：将结果 `push ax` 压入栈顶并保留，示范“结果保存在栈中”的用法；打印时从栈顶读取（用 `BP` 安全访问）但不弹出。
- `sum-plus.asm`：从用户读取字符串（DOS 缓冲输入），把字符串转换为整数（`dec_str2num`），验证范围（1..100），然后计算 1..n 的和并输出；若输入非法则提示错误并退出。

## 关键知识点详解 ✨

### 1) 和的结果表示范围（溢出问题） ⚠️
- `sum 1..100 = 5050`，可以用 16 位或 32 位寄存器表示：
  - 16 位 (word) 最大值 65535，足以保存 5050；但若上界更大（例如 1..1000 = 500500），16 位将溢出（500500 &gt; 65535）。
  - 32 位（dword）可表示到 4,294,967,295，无符号或带符号范围更大。
- 编写汇编/算法时应明确数据位宽：如果预期和可能超出 16 位，需要使用更宽的寄存器（如 `EAX`/`EDX:EAX` 或 32/64 位寄存器）或做溢出检测。
- 溢出检测方法：在加法后检查进位标志（`JC`/`JNC`）或使用更宽寄存器保存中间结果。

### 2) 字符串 <-> 数值 的进制转换（进制转换问题） 🔄
- `sum-plus.asm` 的 `dec_str2num` 子程序实现（十进制）：
  - 遍历输入字符：把字符 `'0'..'9'` 转为数值 `0..9`（`sub al, '0'`）。
  - 逐位累乘 10（`mul 10`）再加当前数字，得到十进制数。注意乘法可能导致溢出，必要时扩大位宽。
- 输出数值为字符串：通过循环 `div 10` 逐位取余（余数为最低位），把各位余数压栈，再弹出并加 `'0'` 输出 ASCII。此法需要保存/恢复寄存器并处理 0 值特殊情况。
- 进制扩展：若需做十六进制/二进制显示，改变基数（10 → 16 或 2）并相应地处理位转换与字符映射（0..9/A..F）。

### 3) 结果存放位置的差异：寄存器 / 数据段 / 栈 📍
- 寄存器（如 `AX`, `EAX`）
  - 优点：访问最快，适合短期保存与计算。
  - 缺点：函数调用、中断或其它代码可能改写寄存器，需要注意保存（`push`/`pop` 或使用调用约定）或避免跨调用长期依赖。
- 数据段（全局变量，如 `sum dw`）
  - 优点：持久保存、全程序可访问，适合在多个函数间共享结果。
  - 缺点：访问稍慢（内存访问），并占用静态数据区。
- 栈（通过 `push` 将结果放入栈）
  - 优点：局部保存、可被子程序安全访问（结合 BP），适合按需保存状态。
  - 注意：要注意栈平衡（每个 `push` 最终应被 `pop`，或明确保留以在函数结束时清理），以及 16 位下使用 `[bp+offset]` 方式访问栈参数/局部。

## DOS `int 21h` 常用功能表（与本作业使用相关） 🧾
- AH=09h：输出 `$` 结尾的字符串（参数：`DS:DX` 指向字符串，直到 `$` 结束）。
- AH=02h：显示单字符（参数：`DL` 内的字符 ASCII）。
- AH=0Ah：缓冲输入（参数：`DS:DX` 指向输入缓冲区，缓冲格式：第一字节为缓冲区长度，第二字节为实际输入长度，字符从第三字节开始）。
- AH=4Ch：退出程序并返回到 DOS（返回值在 `AL` 或 `AX` 中）。

注意：`sum-plus.asm` 使用了 AH=09h 输出提示和结果子串，使用 AH=0Ah 实现缓冲输入并随后在程序内部调用 `dec_str2num` 将 ASCII 转为整数。

## 反汇编要点（`sum-disasm.asm` / `sum-plus-disasm.asm`）🧩
- 反汇编展示了编译器如何为局部变量分配栈帧（`push rbp; mov rbp, rsp; sub rsp, N`）并用 `[rbp-offset]` 存取。
- `sum-disasm.asm`：循环用 `cmp`/`jle` 实现；结果作为参数传给 `printf`（参数寄存器：`RDI`, `RSI` 等）。
- `sum-plus-disasm.asm`：展示了字符串处理的步骤——`fgets` 读取、`strlen` 得到长度、去掉末尾的 CR/LF、字符逐个验证是否为数字、调用 `strtol` 转换成整数，以及用 64 位寄存器计算和并传给 `printf`。

## 学习心得 & 建议 ✍️
- 理解数值位宽与溢出是写正确汇编程序的基础，在处理用户可控输入（如 `sum-plus.asm`）尤其重要：要验证范围并选择合适位宽。
- 字符串与数值之间的转换是常见操作，掌握逐位乘加（乘基数加当前值）与除基数取余（逆序输出）对编写 I/O 子程序很有帮助。
- 在汇编中管理数据位置（寄存器、数据段、栈）需要考虑访问速度与生命周期，选择合适策略并严格保持栈平衡与寄存器保存约定。
